# Final Ad Scripts — all campaigns

All scripts below are FINAL: they carry every locked rule (simple words,
direct hooks, one-visit clarity, free/paid split in plain numbers, no
"trial"/"demo" labels, no jargon, brand said once, scarcity line, Meta
compliance). English by default; Tamil only where explicitly requested.

Production note: every ad is built on the SWAPPABLE OFFER BLOCK template —
hook / proof / offer / end frame. Only the offer block's voiceover and text
cards change between offers. Footage is never re-shot.

customers, sales, videos. Hidden funnel step: the in-person shoot

# D. CAMPAIGN SETUP NOTES
================================================================
- Objective: Messages / click-to-WhatsApp (never boosted post with
  comment-bait).
- Targeting: BROAD - location + age only, no detailed interests. The
  creative is the targeting; Meta reads the voiceover transcript, the
  on-screen text and the caption, then learns from who engages first.
- Cover frame: use the biggest text card (e.g. "பிடிச்சா ₹500. பிடிக்கலைனா ₹0.")
- One DM keyword per ad so the inbox reveals which offer and which hook won.
- Let each round run 3-4 days before judging.
